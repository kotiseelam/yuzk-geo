# Yuzk Geo — Chrome Extension

Every new tab becomes a mini geography lesson: a real photo from around the world with its story, plus a "where is this?" quiz that builds a daily streak.

## Files

- `manifest.json` — Manifest V3; overrides the New Tab page
- `newtab.html` — the new-tab page (loads `geo.html` full-screen)
- `geo.html` — the entire app (Discover + Quiz, live Wikipedia data)
- `icon128.png` — extension icon (generated by `make-icon.js`)
- `make-icon.js` — regenerates the icon: `node make-icon.js`

## Install locally (Chrome / Edge / Brave)

1. Open `chrome://extensions` (Edge: `edge://extensions`)
2. Enable **Developer mode** (top right)
3. Click **Load unpacked**
4. Select this `extension/` folder
5. Open a new tab → Yuzk Geo appears. 🌍

## Publish to Chrome Web Store (later)

1. Zip the folder contents (manifest at zip root): e.g. `cd extension && zip -r ../yuzk-geo.zip .`
2. Sign up at https://chrome.google.com/webstore/devconsole (one-time $5 registration)
3. Upload the zip, fill in store listing (screenshots + description), submit for review

## Notes

- Data is fetched live from Wikipedia's REST API (CORS-open, no key)
- Streak and score are stored in `localStorage` (per-browser)
- Same design language as the Yuzk brand: `#7c5cff → #00e0c6 → #ff5ca8` on `#07070b`
